# Лабораторна робота №3

**Левківський Євгеній Сергійович · ІПС-41**

Перше завдання: знайти найбільшу кількість речень тексту, в яких є однакові слова.

```powershell
.\.build\lab3.exe lab3/examples/textbook.txt
.\.build\lab3.exe lab3/examples/textbook.txt --output lab3/results.txt
```

Програма читає UTF-8 файл, прибирає BOM, замінює табуляції та послідовності пробільних символів одним пробілом. Типи `Character`, `WordToken`, `Punctuation`, `Element`, `Sentence`, `Document` явно відокремлюють складники тексту.

Регістр не впливає на порівняння; типографські апострофи нормалізуються. Апостроф чи дефіс усередині слова зберігається. Речення завершуються `.`, `!`, `?`, послідовність `?!` — одна межа. Крапка між цифрами в `3.14` не завершує речення. Останній фрагмент без кінцевого знака також обробляється. Скорочення на кшталт `т.д.` окремо не розпізнаються.

Для кожного речення спочатку створюється множина слів. Тому десять повторень слова в одному реченні дають один внесок у результат. Далі `Map WordToken [Int]` накопичує номери речень; знаходяться максимум та всі слова з цим максимумом. Для порожнього тексту максимум дорівнює 0; якщо спільних слів немає — 1.

Фактичний результат прикладу: **11 речень; слово «значення» трапляється в 5 реченнях: 2, 4, 7, 10, 11.** Повний вивід: [results.txt](results.txt). Звіт: [PDF](report.pdf), [DOCX](report.docx), [Markdown](report.md).
