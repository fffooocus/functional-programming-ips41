# Лабораторна робота №3 — завдання 3

**Левківський Євгеній Сергійович · ІПС-41**

Знайти слово в першому реченні, якого немає в жодному з інших речень.

```powershell
.\.build\lab3.exe lab3/examples/textbook.txt
.\.build\lab3.exe lab3/examples/textbook.txt --output lab3/results.txt
```

Типи `Character`, `WordToken`, `Punctuation`, `Element`, `Sentence`, `Document` описують структуру тексту. Файл читається як UTF-8, BOM прибирається. Табуляції та послідовності пробільних символів замінюються одним пробілом.

Програма створює множину слів усіх речень, крім першого. Далі переглядає слова першого речення в початковому порядку та залишає ті, яких немає в цій множині. Повторення усуваються. Виводиться перше відповідне слово та список усіх допустимих відповідей. Якщо відповіді немає, друкується явне повідомлення. Для одного речення підходять усі його різні слова.

Порівняння не залежить від регістру; типографські апострофи нормалізуються. Апострофи й дефіси між літерами входять до слова. Межі речень: `.`, `!`, `?`; група `?!` є однією межею. Крапка між цифрами в `3.14` не завершує речення. Скорочення та морфологічні форми окремо не розпізнаються.

Для прикладу з 11 речень відповідь: **«функціональна»**. Усі допустимі слова: **«функціональна», «програмування»**. Повний результат: [results.txt](results.txt). Звіти: [PDF](report.pdf), [DOCX](report.docx), [Markdown](report.md).
