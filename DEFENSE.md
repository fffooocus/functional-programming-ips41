# Пояснення для захисту

**Левківський Євгеній Сергійович · ІПС-41**

## Лабораторна №1

**Чим class відрізняється від instance?** `class` оголошує набір операцій для типів, `instance` задає реалізацію для конкретного типу. `ResourceStore` оголошує CRUD; `instance ResourceStore MySQL` виконує SQL-запити.

**Де тут функціональний підхід?** Валідація та SQL-кодування є чистими функціями. Взаємодію із сервером винесено в `IO`. Алгебраїчні типи описують ресурс, чернетку й налаштування БД.

**Навіщо 11 таблиць?** Автори, види, умови й призначення виділені в довідники. Зв’язки багато-до-багатьох реалізовані таблицями `resource_authors` і `resource_purposes`. Адреси, користувачі, доступ і використання зберігаються окремо. Дублювання даних зменшується.

**Як формується статистика?** `LEFT JOIN` зберігає ресурси без відвідувань; `COUNT` рахує події та різних користувачів, `SUM` — тривалість. Представлення не дублює дані.

**Чи є це справжнім MySQL?** Так. Дані зберігаються на MySQL Server 8.4.6. Haskell запускає офіційний консольний клієнт як транспорт, передає SQL через stdin і читає рядки результату. SQLite або JSON замість БД не використовується.

**Як захищено текстові значення?** UTF-8 текст кодується hex-літералом; лапки та SQL-оператори залишаються даними. Назви таблиць для `edit` перевіряються за білим списком, числові ID розбираються як `Int`.

## Лабораторна №2

**Як працює Хаффман?** Рахуємо частоти байтів, створюємо листки, послідовно зливаємо два вузли з найменшою частотою. Ліва гілка відповідає 0, права — 1. Часті байти зазвичай мають коротші коди. Префіксність дозволяє однозначне декодування.

**Що паралелиться?** Незалежне стиснення окремих файлів. Фіксований пул отримує роботи через `Chan`; готові результати впорядковуються відповідно до вхідного списку. Один файл не розбивається між потоками.

**Навіщо -threaded та -N?** `-threaded` підключає багатопотокову RTS. `-N4` створює чотири capabilities для виконання Haskell-коду на кількох ядрах. Сам `forkIO` без кількох capabilities не забезпечує одночасного виконання чистих обчислень на кількох ядрах.

**Навіщо force?** Через ліниві обчислення потік міг би передати невиконану роботу. `evaluate (force ...)` гарантує обчислення результату в робочому потоці до його публікації.

**Чому прискорення не дорівнює 4?** Є створення потоків, синхронізація, розподіл роботи, робота GC і пропускна здатність пам’яті. Формули: S(k)=T(1)/T(k), E(k)=S(k)/k. Виміряно S(4)=2.9352 та E(4)=0.7338.

**Що саме вимірювалось?** Стиснення восьми попередньо завантажених файлів по 1 МіБ, три повторення, медіана. Після кожного запуску перевірялося відновлення, але поза таймером. Читання, запис і розпакування в наведений час стиснення не входять.

**CRC32 шифрує дані?** Ні. Це контрольна сума для виявлення випадкового пошкодження; криптографічної автентичності вона не забезпечує.

## Лабораторна №3

**Що означає найбільша кількість речень?** Для кожного слова рахується кількість різних речень, у яких воно зустрічається. Береться максимум; виводяться всі слова, що його досягають, і номери речень.

**Як уникнути подвійного підрахунку?** Слова кожного речення перетворюються на `Set`; одне слово дає один внесок на речення.

**Як обробляється українська?** Файл читається як UTF-8. `isAlpha` розпізнає Unicode-літери, `toCaseFold` нормалізує регістр, апострофи зводяться до однакової форми.

**Яка складність?** Токенізація лінійна за кількістю символів. Множини й словник мають логарифмічні операції; основний аналіз займає O(W log V), де W — кількість слів, V — кількість різних слів. Пам’ять залежить від тексту й індексу входжень.

**Який результат прикладу?** 11 речень. «значення» — у п’яти: 2, 4, 7, 10, 11. Два повторення в другому реченні враховуються один раз.
