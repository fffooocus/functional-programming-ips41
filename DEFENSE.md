## Лабораторна №1

**Яку систему розроблено?** «Програмне забезпечення на мережі факультету». Кожна програма має назву, версію, авторів, вид, анотацію, термін та умови використання; пов’язані таблиці містять дистрибутиви, користувачів і події використання.

**Що означають class та instance?** class задає інтерфейс операцій, instance — реалізацію для конкретного типу. ResourceStore оголошує CRUD, instance ResourceStore MySQL виконує запити. SqlValue перетворює типізовані значення на SQL, Validatable перевіряє чернетку запису.

**Навіщо 11 таблиць?** Довідники авторів, видів, призначень та умов не дублюються в кожному записі. Таблиці зв’язків реалізують багато-до-багатьох. Адреси дистрибутивів, користувачі, права доступу й історія запусків зберігаються окремо.

**Як визначається популярність?** Представлення підраховує запуски, різних користувачів і тривалість. Сортування за кількістю подій показує популярність. LEFT JOIN включає програми без запусків.

**Чи справжня БД?** Так, MySQL Server 8.4.6. Офіційний клієнт mysql використовується як транспорт через stdin/stdout, а моделі, правила, запити та інтерфейс реалізовано Haskell. Текст кодується UTF-8 hex-літералами; імена таблиць для edit перевіряються за списком.

## Лабораторна №2

**Як працює метод Гаусса?** Прямий хід зануляє коефіцієнти під головною діагоналлю. Зворотний хід знаходить невідомі від останнього рівняння до першого.

**Навіщо головний елемент?** Вибір найбільшого за модулем коефіцієнта поточного стовпця зменшує проблеми від ділення на мале число; за потреби міняємо рівняння місцями. Нормалізація рядків зменшує вплив різних масштабів рівнянь.

**Що паралелиться?** На кроці k перетворення кожного рядка нижче головного незалежне від інших. Працівники обчислюють a'ij = aij - (aik/akk)akj. Після фази є бар’єр; наступний головний елемент залежить від усіх оновлень.

**Навіщо threaded, N та force?** -threaded підключає багатопотокову RTS, -N4 дає чотири capabilities. force змушує працівника завершити обчислення до передавання результату. UArray зберігає обчислені числа Double без проміжних лінивих списків результату.

**Що робити з виродженою системою?** Програма повідомляє SingularSystem, коли єдине чисельно стійке рішення не визначається. Несумісні системи й системи з безліччю рішень не видаються за єдине рішення.

**Як перевірено відповідь?** Для прикладу x=(2,3,-1), Ax-b=0. Для згенерованих діагонально переважних матриць відоме x; перевіряються і помилка x, і відносна нев’язка.

**Яка складність?** O(n³) арифметичних операцій, O(n²) пам’яті. Паралельність не прибирає послідовний вибір головного елемента та бар’єри.

**Чому чотири потоки повільніші?** При N=384 витрати створення працівників і синхронізації на кожному кроці переважають виграш. Медіана: 1 потік — 0.340895 с, 2 — 0.273305 с, 4 — 0.362693 с. Дані наведено без приховування уповільнення.

## Лабораторна №3

**Який алгоритм?** Зібрати в Set слова всіх речень, крім першого. Переглянути перше речення й знайти слово, що не належить Set. Усі варіанти зберігаються в початковому порядку без повторень.

**Чому не порівнювати лише з другим реченням?** Умова вимагає відсутності в кожному з інших речень. Тому множина охоплює весь залишок тексту.

**Як оброблено українську?** UTF-8, Unicode isAlpha, toCaseFold та нормалізація апострофів. «Пам’ять» і «пам'ять» однакові; відмінкові форми вважаються різними словами.

**Які крайові випадки?** Порожній текст — відповіді немає. Одне речення — підходять усі його слова. Усі слова першого є далі — відповіді немає. Результат прикладу: «функціональна»; також підходить «програмування».

**Яка складність?** Токенізація O(C), множини — O(W log V), де C — число символів, W — число слів, V — число різних слів.
