# Лабораторна робота №2 — завдання 3

**Левківський Євгеній Сергійович · ІПС-41**

**Паралельний метод Гаусса** для систем лінійних рівнянь.

```powershell
.\.build\lab2.exe solve 4 lab2/examples/system.txt +RTS -N4 -RTS
.\.build\lab2.exe solve 4 lab2/examples/system.txt --output lab2/results.txt +RTS -N4 -RTS
.\.build\lab2.exe solve 2 lab2/examples/pivot.txt +RTS -N2 -RTS
node scripts/benchmark.mjs
```

Збирання: `-O2 -Wall -threaded -rtsopts`. Аргумент `4` задає число працівників; `+RTS -N4` дозволяє виконання на чотирьох ядрах.

Формат файла: перший рядок — N, далі N рядків із N коефіцієнтів і правою частиною. Допускаються пробіли, порожні рядки та коментарі після `#`. Приклад:

```text
3
2 1 -1 8
-3 -1 2 -11
-2 1 2 -3
```

Результат: **x1=2, x2=3, x3=-1**, максимальна абсолютна й відносна нев’язки — **0**. [Фактичний вивід](results.txt).

Рядки нормалізуються на найбільший за модулем коефіцієнт. На кожному кроці обирається найбільший за модулем головний елемент; рядки переставляються. Незалежні перетворення решти рядків виконує обмежений пул `forkIO`/`Chan`. Перед наступним кроком очікуються всі результати. Зворотний хід послідовний.

Нульові чи чисельно малі головні елементи (≤1e-12 після нормалізації) дають `SingularSystem`: єдине стійке рішення не визначається. Окремо перевіряються розміри, кількість потоків, NaN/Infinity та переповнення. Максимальний порядок — 2000; дані обробляються в пам’яті, використовуються Double.

Нев’язка: `max |Ax-b|`. Відносна нев’язка: `||Ax-b||∞ / (||A||∞ ||x||∞ + ||b||∞)`.

[CSV](benchmark.csv) і [журнал](../verification/benchmark.txt) містять фактичні вимірювання для N=384 і медіани трьох запусків. Два працівники дали прискорення 1.2473; чотири — 0.9399, тобто на цій задачі синхронізація перекрила виграш. Перевірено матриці з відомим рішенням і послідовно-паралельну тотожність.
